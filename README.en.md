# SRR-SB

Automated generation of sing-box RULE-SET `srs` files

Source files used: Xray `dat` files from the [frayZV/simple-ru-routing](https://github.com/frayZV/simple-ru-routing)

Based on the [runetfreedom/geodat2srs](https://github.com/runetfreedom/geodat2srs) converter.
